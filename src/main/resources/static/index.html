AI 助手未启用

后端需要两个配置才能开启：app.ai.enabled=true 和一个 DEEPSEEK_API_KEY 环境变量。

这是刻意的默认值 —— AI 层依赖外部付费接口， 默认关闭才能保证 clone 下来不配任何东西也能把服务跑起来， 记账、打卡、统计这些核心功能完全不受影响。

bash：export DEEPSEEK_API_KEY=sk-xxx && AI_ENABLED=true ./mvnw spring-boot:run
cmd ：set DEEPSEEK_API_KEY=sk-xxx && set AI_ENABLED=true && run.cmd

只读查询，不会修改任何数据；只会查到你自己账号的数据。 会话保存在服务端内存里，默认空闲 30 分钟过期，服务重启即丢。
